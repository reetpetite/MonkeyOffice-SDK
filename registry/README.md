# Traceability registries

These registries provide the machine-readable edges of the evidence graph.
They do not duplicate the full content of experiments, evidence records, or
specification rules.

- `experiments.yaml` registers reproducible research inputs.
- `evidence.yaml` registers atomic evidence records.
- `specification.yaml` links normative rules to supporting evidence.

Identifiers are permanent. Removing or reusing an identifier is not permitted.
A registry path must point to a version-controlled repository file.
