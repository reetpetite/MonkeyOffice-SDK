# Design Decisions

This directory records repository-wide architectural decisions. It does not
contain normative MonKey Office language rules.

Each decision record uses the following compact structure:

- **Status** — proposed, accepted, superseded, or rejected
- **Context** — the problem and relevant constraints
- **Decision** — the chosen project rule
- **Consequences** — expected benefits, costs, and follow-up work

Decision identifiers are permanent. A superseded decision remains in the
repository and links to its replacement.
